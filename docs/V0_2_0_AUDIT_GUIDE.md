# v0.2.0 明早审计入口

App 版本：0.2.0（build 2）。视频：`promo-video/renders/worthly-promo-v0.2.0.mp4`，82 秒、1080p、30 fps。

## 先看视频

| 时间 | 内容 |
| --- | --- |
| 0–23 秒 | 记下想要、7 天后重看、买了或没买、购买价格 |
| 23–35 秒 | 补录过去购买、7 / 30 / 90 天阶段回访 |
| 35–48 秒 | 完整待办、随时回访、修改或删除旧回访 |
| 48–68 秒 | 搜索筛选、期待与满意度、折扣与类别规律、长期购买记忆 |
| 68–82 秒 | 本地保存、导出与删除、可选提醒、深浅外观 |

视频持续标明功能演示及示例数据。74–78 秒深浅外观段落改为当前 App 的完整首页模拟器实屏，包含系统状态栏、真实悬浮导航、回访与最近购买各一张卡片；其余界面仍明确标为重绘。用户手机截图仅用于核对颜色和布局，没有放进素材或成片。导出采用无损 PNG 中间帧与明确的 BT.709 色彩转换 / 标记，并检查成片解码画面。画面不是实机录屏；示例数据由本地规则计算，未回访与没买记录不参与满意度。钢琴配乐与片尾「更多功能，敬请期待」「尚未正式上架 App Store」均保留。

## 再看 App 的主要变化

1. 已购详情 → AFTER → 旧回访右侧「编辑回访」。修改评分、使用频率、备注；保存后原日期和阶段应保留。新的一次感受仍从「记录现在的感觉」进入。
2. 在编辑回访页确认删除一条阶段回访。其他回访应保留，被删除的阶段重新待回访；随时回访的增删改不影响阶段和提醒。
3. 首页有超过三件待回访或待决定时，点「查看全部」。列表应包含全部待办；完成一件后应更新。
4. Add / Edit / Buy / Check-in 表单检查键盘「完成」、滚动收键盘、多行备注和使用频率菜单。开启较大字体，检查选项和分数是否可读。
5. 修改带多位小数价格的记录名称。导出的原始价格应保持；页面货币格式仍按正常精度显示。
6. 我的 → 提醒：授权期间显示进度；拒绝后可打开系统设置。我的 → 导出：分享说明可滚动，弹窗可展开。
7. 切换系统深浅外观，检查强调卡小字和表单提示。App 继续跟随系统。

通知的早晨可填写、过期通知、弹窗等待以及关闭提醒后的异步竞争已修复。前台、后台、退出后的通知点击等实机步骤详见 `TESTFLIGHT_CHECKLIST.md`，本次没有声称已完成这些真机检查。
